The [items system](/packages/reldens-items-types/docs/api/index) is the engine for adding, holding, and trading items. This example runs a real trade between two players, then shows how to verify the item data with the [`@reldens-community/items-types`](/packages/reldens-items-types/docs/api/index) zod schemas without the game code depending on them.

## What it produces

`npm start` builds two inventories, trades a sword for 50 gold, then builds a custom item type:

```text
Before trade:
  Alice: iron_sword x1
  Bob:   gold x100
After trade:
  Alice: gold x50
  Bob:   gold x50, iron_sword x1

Custom item type:
  built a Runestone -> Fire Rune (fire +5)
  element: fire power: 5
```

## The one idea

The game code imports `@reldens/items-system` and nothing else. Validation is a separate, deletable layer.

<CardGroup cols={2}>
  <Card title="The app" icon="gamepad">
    `src/` - plain data plus the engine. Copyable into any project that has `@reldens/items-system`. No zod at runtime.
  </Card>
  <Card title="The check" icon="circle-check">
    `optional-validation/` and `test/` - zod-verify the same data against the types package. Delete them and the game still runs.
  </Card>
</CardGroup>

## Run it

```bash
npm start      # the trade demo (uses @reldens/items-system only)
npm run verify # opt-in: zod-check the catalog
npm test       # the same check as a repeatable test
npm run typecheck
```

<Info>
Verified against `@reldens/items-system@0.49.0` and `@reldens-community/items-types@0.1.0`.
</Info>
